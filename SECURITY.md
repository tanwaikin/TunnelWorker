# Security policy

Once the first release is published, security fixes will target the latest stable release. Older releases may not receive fixes; update before reporting an issue.

Please report vulnerabilities through GitHub's private vulnerability reporting feature for this repository. Do not post exploit details, credentials, or affected live hostnames in public issues or discussions. The repository owner must enable private vulnerability reporting in GitHub settings before the repository is made public.

Do not test against another person's Worker, domain, or local service without their permission.
